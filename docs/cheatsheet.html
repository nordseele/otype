Reading a line

One command per line, in prefix notation: an operation takes the values that follow it, which may be operations themselves. Modifiers before : repeat or condition the rest of the line; a line ending with : opens an indented block.

l 1 16: prob 35: tr.add i        # for i = 1..16, 35 % chance: a trig on step i
pl.set i amp.vol rrand 70 127    # = pl.set (i) (amp.vol) (rrand 70 127)
steps has.trig:                  # block: the steps that have a trig
  each: cond.set i 50%

Dotted names (tr.add) are the OT's API; your own functions use underscores and take their arguments after |. OType ignores case; this reference writes everything in lowercase. Text between quotes keeps its case.

Read a setting with x tempo; write it with tempo 137. Numbered settings keep their number: x lfo.wave 1 / lfo.wave 1 18. Renamed operators have no compatibility aliases.

Names such as amp.vol and lfo.spd 1 identify a parameter. Read/write its value with par.get/par.set, or use pl.* for a step lock. SETUP operations such as lfo.mult 1 3 write the setting directly.

01 Structure

define a function (a brick when it has no menu); body indented below

file-level constant (number, string, list or condition), global to all files
menu "level" >> "action"
place of the function in the menu (levels up to 6 chars, action up to 10)
page "label"
list the function on the SCRIPT page of the unit (label 1..8 characters; no argument, at most 6 params, no card/slot/pool op)
var name init
persistent variable initialized to init (integer constant) on script load
in clock n: | in note [ch]: | in cc ch n: | in trig t [all]:
event block for periodic clock, incoming MIDI note / CC events, or the sequencer's trigs
launch n
live script: quantize the first wake to the next multiple of n ticks of the grid (96 = a beat)
param name [int] d min max | bool d | option d "a"... | folder "path"
a setting editable on the unit: number in range, bool (yes/no), option (labels) or folder browser
confirm ["text"]
ask YES/NO before running (implied by destructive operations)
input sample
placement header: function acts on the host audio sample context

02 Modifiers

if c: ...
run the line or block when c is true
elif c: ...
after an if/elif at the same indentation: another condition
else: ...
after an if/elif at the same indentation: the remaining case
l a b: ...
loop i from a to b inclusive; bounds are constant (never a variable)
each: ...
for each step of the context, in order (i = the step)
prob p: ...
run with p percent probability
every n: ...
run once every n passes over this line
skip n: ...
run every time except once every n passes
del n: ...
reserved: run n steps later (not available yet)

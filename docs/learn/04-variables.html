Variables and memory

A variable holds a number. What sets OType's variables apart is how long they keep it: for one run, from one press to the next, or for the life of a live script. This study builds a rhythm that turns a little further on each press, and a function that alternates between two patterns.

Giving a variable a value

A line that starts with a variable gives it a value; anywhere else, the variable is read.

def count_up
  menu "LEARN" >> "COUNT UP"
  a 5
  a add a 1             # read a, add 1, store the result back in a
  b mul a 2
  msg "A" a "B" b

There is nothing to declare for the one-letter variables: they are always there, and start at 0.

Four kinds of letters

nameskindkeeps its value
a b c dlocalfor one run of one function. Every call has its own: a function you call cannot change yours. 0 at the start of each run.
x y z tglobalfrom one press to the next, shared by every function in every file. 0 when the machine starts.
i jcountersset by the loops (i the inner loop, j the one around it); read-only

Use a b c d for working values, and keep x y z t for what really has to survive the press, since every function can change them.

One press A, the next press B

not x is 1 when x is 0, and 0 otherwise. Storing it back in x on each press makes x alternate: 1, 0, 1, 0…

def ab_rhythm
  menu "LEARN" >> "A/B"
  x not x
  tr.clr
  if x: l 1 16: if er 5 16 i: tr.add i
  else: l 1 16: if er 3 8 i: tr.add i

Variables with a name: var

When a function needs to remember something of its own, give it a named variable. var name start goes at the top of the function, before the first statement; the variable starts at start when the scripts are loaded and keeps its value from one press to the next. Unlike x y z t, it belongs to its function alone. A function may have up to 16 of them.

def rotate
  menu "LEARN" >> "ROTATE"
  var shift 0
  shift wrap add shift 1 0 15
  tr.clr
  l 1 16: if er.r 5 16 shift i: tr.add i
  msg "SHIFT" shift

er.r is er with one more value, a rotation. wrap … 0 15 brings 16 back to 0, so the rhythm comes round after sixteen presses.

Names you can read but not change

A param, a const and the arguments of a function are read like variables, but cannot be assigned: gap 3 on a param gap is an error. You will meet const and arguments in functions.

Values that move by themselves

Three words read like variables but change each time they are read. Each function has its own, kept between presses.

readgivesset with
flip0, 1, 0, 1… one more at each readflip 0
oa counter: 0, 1, 2… up to o.max (63), then round againo 0 · o.min · o.max · o.inc · o.wrap
drunka random walk: one step down, none or one step up at each readdrunk 64 · drunk.min · drunk.max · drunk.wrap
 
def wander
  menu "LEARN" >> "WANDER"
  drunk.max 15
  drunk 12
  tr.clr
  l 1 16:
    tr.add i
    pl.set i amp.vol add 7 mul drunk 8

drunk walks between 0 and 15 here; add 7 mul drunk 8 turns each of its steps into a clear change of volume, from 7 to 127.
